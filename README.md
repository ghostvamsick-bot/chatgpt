# Vamsick Flixer

Flixer-inspired streaming landing page with a lightweight Node backend.

## Quick start

```bash
npm run start
```

Then open `http://localhost:3000`.

## API endpoints

- `GET /api/status`
- `GET /api/spotlight`
- `GET /api/genres`
- `GET /api/collections`
- `GET /api/search?q=atlas`
