# Flixer Vamsick

A Flixer-inspired streaming landing page with a lightweight Express backend.

## Getting started

```bash
npm install
npm run start
```

Open `http://localhost:3000` to view the site.

## API endpoints

- `GET /api/health`
- `GET /api/catalog`
- `GET /api/featured`
- `GET /api/search?q=term`
